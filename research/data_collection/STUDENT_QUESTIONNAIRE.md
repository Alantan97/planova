## A. Programme and current planning

4. **Programme.** Required single choice: Software Engineering / Information Technology / Creative Multimedia. Replace with official names after confirmation; do not infer programme from course code alone.
5. **Current semester of study.** Required positive whole number. This means your stage of study, not the academic-session code A261/A262.
6. **How do you currently keep track of academic tasks?** Required multiple choice: Phone calendar / Paper planner / Notes app / Task-planning app / LMS announcements / Mostly memory / Other [optional text].
7. **During the past two weeks, which planning difficulties have you experienced?** Required multiple choice: Remembering deadlines / Deciding what to start / Estimating effort / Fitting study around other commitments / Updating plans after changes / None / Other [optional text]. Make None exclusive.
8. **Describe one situation where your study plan changed.** Optional short text. Do not include names or sensitive personal details.

## B. Study preferences

These answers describe what you prefer, not what you must always do. You can change them later. Do not frame a preference as a diagnosis or a medically assessed sleep pattern.

9. **When do you usually prefer independent study?** Required multiple choice: Morning / Afternoon / Evening / Late evening / No preference. Record exact permitted times later; these broad categories must not authorize scheduling during protected sleep time.
10. **How long would you prefer one study session to last?** Required single choice: 25 minutes / 45 minutes / 60 minutes / 90 minutes / Varies / Other [minutes].
11. **How long a break would you prefer between sessions?** Required single choice: 5 minutes / 10 minutes / 15 minutes / Varies / Other [minutes].
12. **What daily maximum would you currently set for independent study?** Required positive number in minutes, or Not sure. Example: 120 minutes. This excludes scheduled classes; it is not a health recommendation.
13. **Do your preferred study times differ across weekdays or weekends?** Optional; Yes / No / Not sure, with an optional brief explanation.

## C. Commitments and protected time

14. **Which recurring commitments should a planner work around?** Required multiple choice: Classes or labs / Part-time work / Clubs or volunteering / Sports / Travel or commuting / Family or personal responsibilities / Other / None. Make None exclusive. Details about the reason for a personal commitment are unnecessary.
15. **Would you want to enter protected sleep times?** Required single choice: Usually the same daily / Different by day / Prefer not to provide. If supplied, ask usual sleep start and wake time as time fields. Explain that an end earlier than a start means the next day; do not infer a sleep disorder. Students who skip this can still specify allowed study windows explicitly.
16. **Would you prefer a planner to schedule only within study windows you explicitly allow?** Required; Yes / No / Not sure. This is requirements feedback, not permission for the research team to alter the student's calendar.
17. **Would you be willing to provide a simplified weekly availability table for the pilot?** Optional; Yes / No. Do not ask for a timetable screenshot containing identifying information by default.

Use the separate availability table in `TASK_SNAPSHOT_TEMPLATE.md` when detailed times are needed. One row records one time block; a single day can have several rows. Explicit allowed windows minus blocked commitments determine availability. Free-looking calendar time is not automatically study time.

## D. Control and understanding

18. **If a study session is missed, what would you prefer?** Required single choice: Review changes before applying / Apply changes automatically with an explanation / Decide manually each time / Not sure.
19. **What would you want to know before accepting a study plan?** Required multiple choice: Why a task comes first / Total study time per day / Breaks / Which tasks cannot fit / What moved after a change / Other [optional text].
20. **What should Planova never move without your approval?** Optional short text; generic activity labels only.
21. **Would you like to participate in the optional task-snapshot pilot?** Required; Yes / No. This is willingness only; explain the actual follow-up procedure before collecting it. Arrange recruitment/contact separately.

## Researcher notes

- Start with a small pilot and record actual completion time; do not claim a survey duration before testing it.
- Do not use this questionnaire alone as LambdaMART training data. It lacks sets of concurrently active tasks with preferred task order.
- Keep preferences editable and dated; a one-time answer may change.
- Use participant codes across linked collections, but keep any identity/code lookup separate and access-restricted.
- If collecting a Malay version, review the translation and pilot the same difficulty/importance/ranking definitions; record questionnaire language and version. An English-only draft may limit who can comfortably participate.
- Preserve original responses. Cleaning and coding happen in a separate working copy.
