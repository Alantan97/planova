# Planova Development Instructions

You are assisting in the development of Planova, an AI-powered adaptive study planner built with Flutter.

## Project Context
- Read `PLANOVA_CONTEXT.md` before planning or implementing features.
- Use that document as the primary product reference.
- Inspect the existing Flutter project before making changes.

## Development Guidelines
- Follow Flutter and Dart best practices.
- Use null-safe, readable, maintainable code.
- Organize implementation into reusable widgets, screens, models, services, and state management as appropriate.
- Maintain consistent design throughout the application.
- Avoid unnecessary packages and overengineering.
- Preserve existing working functionality.
- Explain important technical decisions briefly.
- Run Flutter analysis and relevant tests when available.
- Fix errors introduced by your changes.

## Current Priority
Prepare an interactive, polished Android prototype for the 31 October 2026 innovation showcase.

Focus on the interface, navigation, and realistic demonstration flows before implementing the actual AI models or backend.

## Workflow
- Work incrementally rather than implementing the entire application in one task.
- Before major changes, provide a short implementation plan.
- Keep changes within the requested scope.
- After each task, summarize the files changed, what works, and what remains.
- Ask for clarification when an important product decision is genuinely ambiguous.
- Never describe simulated AI features as real trained AI functionality.
